# Venomite source preservation

The original Venomite 718 source package and its nested cache archive are being
preserved as GitHub release assets at the user's explicit request. The normal
727 cache source tree is unchanged.

[Preserved source and cache downloads](https://github.com/fooliosissir-cmd/BurialGrounds-CacheSource/releases/tag/external-venomite-718-source)

The preservation workflow checks both archives against the existing inventory
hashes and runs archive-integrity checks. It publishes exact original bytes,
checksums, file listings and provenance notes. No bundled program is executed.
The download link is available only after the workflow succeeds.

These files are external research inputs. A custom-wing search still requires
decoding the foreign item definitions and models; archive presence alone does
not confirm wings or production compatibility.
